SMART ELECTRICITY PROJECT — DEMO DATA IMPORT GUIDE

1. Start the app and open **Data Management** (page 6 in the sidebar).
2. Tick the acknowledgement that demo values are simulated.
3. Click **Import demo data into MySQL**.
   Alternatively, upload `data/demo/SYNTHETIC_demo_monthly_power_supply.csv`, select
   **Synthetic demo data (not official)**, acknowledge the warning, and import.
4. Open **Consumption Analytics** and select April 2019–March 2024 to see the charts.

The demo file has 600 rows: 10 states, monthly from April 2019 through March 2024.
All metric values are simulated for testing the application. This is NOT official CEA
data and must not be used for research, reporting, or real-world conclusions.
